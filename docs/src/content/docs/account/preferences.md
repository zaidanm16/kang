Open **Profile → Preferences** to change Analytics, Appearance, and Language. These preferences change your experience, not another user's gateway permissions.

## The four application themes

| Theme | Appearance |
| --- | --- |
| Classic | Blue-gray background and panels with blue accents |
| Gold | Deep purple/navy background with gold accents |
| Black & Blue | Black background, near-black panels, blue accents; the application default |
| Black & Gold | Black background, near-black panels, gold accents |

In **Appearance**, hover a preview to see its name and temporarily preview that theme. Click the preview to select it. Moving away without selecting restores the saved theme. Keyboard focus can preview choices too; activate the choice to save it. The palette control in the application header also provides theme selection.

The theme choice is saved in browser local storage. Clearing site data or using a different browser can reset the selection. Theme changes do not alter resources, permissions, or your plan. All four themes are available independently of Free/Pro.

This documentation website has its own light/dark control. Changing the docs theme does not change the Kang application theme.

## Language

Select the application language under Preferences or through the header language control. Available languages are **English (US)**, **English (UK)**, **Español**, **Français**, **日本語**, and **Bahasa Indonesia**.

Language affects interface labels and supported date formatting. Technical values such as URLs, resource IDs, plugin names, and your own resource names remain their original values. The docs language selector changes the documentation language separately.

## Analytics preference

Enable Analytics to request traffic, latency, and error metrics, or disable it to skip those requests and keep configuration pages lighter. Your installation still needs a working metrics integration. Turning it on does not create traffic or collect metrics by itself.
