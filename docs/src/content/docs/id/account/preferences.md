Buka **Profile → Preferences** untuk mengatur Analytics, Appearance, dan Language. Preferensi ini mengubah pengalaman penggunaan, bukan izin gateway pengguna lain.

## Empat tema aplikasi

| Tema | Tampilan |
| --- | --- |
| Nila | Latar dan panel abu-abu kebiruan dengan aksen biru |
| Kunang | Latar ungu/navy gelap dengan aksen emas |
| Samudra | Latar hitam, panel hampir hitam, aksen biru; tema default aplikasi |
| Harimau | Latar hitam, panel hampir hitam, aksen emas |

Pada **Appearance**, arahkan kursor ke preview untuk melihat nama dan mencoba tema sementara. Klik preview untuk memilihnya. Meninggalkan preview tanpa memilih mengembalikan tema tersimpan. Fokus keyboard juga dapat menampilkan preview; aktifkan pilihan untuk menyimpan. Kontrol palet pada header aplikasi juga menyediakan pemilihan tema.

Pilihan tema disimpan pada local storage browser. Menghapus data situs atau memakai browser lain dapat mereset pilihan. Perubahan tema tidak mengubah resource, izin, atau paket. Keempat tema tersedia terlepas dari Free/Pro.

Website dokumentasi ini memiliki kontrol terang/gelap sendiri. Mengubah tema docs tidak mengubah tema aplikasi Kang.

## Bahasa

Pilih bahasa aplikasi melalui Preferences atau kontrol bahasa pada header. Bahasa yang tersedia: **English (US)**, **English (UK)**, **Español**, **Français**, **日本語**, dan **Bahasa Indonesia**.

Bahasa memengaruhi label antarmuka dan format tanggal yang didukung. Nilai teknis seperti URL, ID resource, nama plugin, serta nama resource buatan Anda tetap sesuai nilai aslinya. Pemilih bahasa docs mengubah bahasa dokumentasi secara terpisah.

## Preferensi analitik

Aktifkan Analytics untuk meminta metrik trafik, latensi, dan error, atau matikan agar request tersebut dilewati dan halaman konfigurasi lebih ringan. Instalasi tetap membutuhkan integrasi metrik yang berfungsi. Mengaktifkan preferensi tidak membuat trafik atau mengumpulkan metrik dengan sendirinya.
